About This Tool

Accessibility Hackathon 2026

Purpose

This Multilingual Learning Assistant helps people in Ethiopia access information more easily, especially those with disabilities.

Who It Helps

  • Blind / Low Vision: Read Aloud, High Contrast, and text size options.
  • Deaf / Hard of Hearing: Clear written text in both languages.
  • Physical Disabilities: Large buttons and voice input.
  • Refugees & Returnees: Bilingual support.

Goal

To create a simple and inclusive tool that supports learning for everyone.

Created by: Eba Mengistu
